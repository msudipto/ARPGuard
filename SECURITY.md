# Security Policy

## Supported Versions

Because ARPGuard is an instructional lab suite, active development and security updates are targeted exclusively at the primary production branch. 

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take security seriously, especially for tools used in educational environments. If you discover a vulnerability or security flaw within the packet analyzer or web dashboard toolchain, please report it responsibly.

### How to report:
1. **Do not** open a public GitHub issue for security vulnerabilities.
2. Please utilize the **GitHub Security Advisories** feature by navigating to the **"Security"** tab at the top of the repository page and selecting **"Report a vulnerability"** to open a private draft advisory.
3. Alternatively, you can contact the maintainer directly via the email listed on the profile page of **@msudipto**.

### What to expect:
* **Acknowledgment:** You will receive a response confirming receipt within **3 business days**.
* **Status Updates:** We will keep you updated on our progress as we triage, analyze, and build a fix for the problem.
* **Resolution:** Once a patch is developed, it will be merged into the `main` branch, and a public advisory/release note will be issued to notify instructors using the platform.
